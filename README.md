# Application Support Incident Lab

This repository simulates a production SaaS/ERP ecosystem designed for hands-on application support and incident investigation training. It features a mock environment managing users, orders, and support tickets with intentionally injected system failures.

### Tech Stack & Components
* **Backend & API:** Python (FastAPI) and Postman for API request/response validation.
* **Database:** SQL for querying data consistency and troubleshooting backend gaps.
* **Observability:** Structured application logs analyzed using Linux/Bash commands and Python tools.
* **Infrastructure:** Docker containers and basic GitHub Actions for CI pipeline simulation.

The core objective of this project is to master end-to-end incident resolution, from capturing customer symptoms to log investigation, root cause analysis, and professional documentation.
