# Application Support Incident Lab

[cite_start]This repository simulates a production SaaS/ERP ecosystem designed for hands-on application support and incident investigation training[cite: 2, 3, 17]. [cite_start]It features a mock environment managing users, orders, and support tickets with intentionally injected system failures[cite: 2].

### Tech Stack & Components
* [cite_start]**Backend & API:** Python (FastAPI) [cite: 33] [cite_start]and Postman for API request/response validation[cite: 10, 27].
* [cite_start]**Database:** SQL for querying data consistency and troubleshooting backend gaps[cite: 2, 20].
* [cite_start]**Observability:** Structured application logs analyzed using Linux/Bash commands and Python tools[cite: 2, 3, 43, 50].
* [cite_start]**Infrastructure:** Docker containers and basic GitHub Actions for CI pipeline simulation[cite: 3, 65, 69].

[cite_start]The core objective of this project is to master end-to-end incident resolution, from capturing customer symptoms to log investigation, root cause analysis, and professional documentation[cite: 4, 24, 81].
